# Scenith Render — agent instructions

- All files (code, docs, comments, ADRs) are written in English.
- Design lives in [`docs/`](docs/README.md); work is planned in
  [`docs/tasks/`](docs/tasks/README.md). Implement from the docs, and update
  them in the same change when behavior differs.
- Follow the clean-room and naming policy in
  [`docs/11-legal-and-clean-room.md`](docs/11-legal-and-clean-room.md).

## Commits

- Single-line Conventional Commits, as defined in
  [CONTRIBUTING.md](CONTRIBUTING.md#commit-messages).
- No body, no trailers, no `Co-Authored-By` or any AI/tool attribution.
- The `commit-msg` hook enforces this; never bypass it with `--no-verify`.
